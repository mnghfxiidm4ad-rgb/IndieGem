Safe Place

Yonis 無料 ユーザーレビューはありません 0.0% 同接 0

AI 3行サマリー

  1. 完全匿名のボイスチャットのみで心理戦を繰り広げる注目の新作パーティーゲームです。
  2. くだけた質問から深い対話へと変化する中で脱落者を投票で決める斬新なシステムが話題を呼んでいます。
  3. 見知らぬプレイヤー同士が言葉だけで駆け引きを行い、最後まで生き残るか絆を深めるスリルを味わえます。

なぜ今話題なのか：2026年9月のリリースに向けて、完全匿名のボイスチャットだけで進行する斬新な人狼系心理パーティーゲームとして注目を集めています。

バズった経緯：マイクのみを使った完全匿名の会話と、徐々に深くなる質問に答えながら生存者を絞っていく独特のゲームシステムがゲーマーの間で話題となりました。

プレイヤーが評価する沼ポイント

  • 完全匿名だからこそ生まれる本音トークと心理的な探り合いの奥深さ
  • ラウンドが進むにつれて質問のテーマが深くなり、相手の人間性が見えてくる緊張感

注意すべきポイント・賛否両論な点

  • マイクが必須であり、ボイスチャットでの積極的な発言が求められる点
  • 日本語非対応のため、英語などの外国語で円滑に会話できる語学力が必要な点

動作環境・言語目安

マイクの接続が必須です。グラフィック要件は低いですが、Steamが起動している必要があります。

日本語には対応していません。インターフェースおよび音声会話は英語、フランス語、イタリア語、スペイン語のみとなります。

最低: 64 ビットプロセッサとオペレーティングシステムが必要です OS: Windows 10 64-bit プロセッサー: Intel Core i3-6100 / AMD Ryzen 3 1200 メモリー: 4 GB RAM グラフィック: Intel UHD 630 / NVIDIA GeForce GTX 750 Ti / AMD Radeon RX 550 DirectX: Version 11 ネットワーク: ブロードバンドインターネット接続 ストレージ: 2 GB の空き容量 サウンドカード: Compatible DirectX 追記事項: A microphone is required — the entire game is voice-based.
