Hallowed Core

Pyxis Studios 無料 好評 75.0% 同接 1（+1） 日本語 非対応（インターフェース / 吹き替え / 字幕いずれも公式非対応）

AI 3行サマリー

  1. 基本プレイ無料の物語重視型新作ターン制RPGとして静かな注目を集めています。
  2. 神聖なる核心を目指す青年の葛藤と家族の過去を描く重厚な世界観設定から話題が広がり始めました。
  3. オーソドックスなターン制戦闘と一本道で描かれる濃密なシナリオをじっくり味わえる作品です。

なぜ今話題なのか：無料配信予定のストーリー重視新作RPGとして、クラシックRPGファンからの関心が徐々に高まっています。

バズった経緯：惑星トロワを舞台にした重厚な家族ドラマとクラシックなターン制コマンドバトルが提示され、ストーリー派のインディーゲームファンの間で話題となり始めています。

プレイヤーが評価する沼ポイント

  • 自分の選択と家族の過去に向き合う、一本道だからこそ描ける濃密でドラマチックなシナリオ。
  • 惑星トロワの神聖なる核心部を目指して挑む、王道で洗練されたターン制コマンドバトル。

注意すべきポイント・賛否両論な点

  • リリース前のため具体的なゲームプレイの質感やボリューム感は未知数です。
  • 日本語非対応のため、ストーリーを細部まで楽しむには英語の読解力が必要です。

動作環境・言語目安

必要スペックは極めて軽量（OSやCPU等の指定なし）ですが、ストレージに約1GBの空き容量が必要です。

日本語には対応しておらず、音声・字幕ともに英語のみのサポートとなっています。

最低: OS: Any プロセッサー: Any グラフィック: Any ストレージ: 1000 MB の空き容量 サウンドカード: Any VRサポート: None
